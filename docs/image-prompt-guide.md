# ChatGPT 이미지 생성 규칙

## 원칙

- 선택지마다 **옷에 어울리는 다른 인물**로 만든다 (예: 운동복이면 숏컷에 통통 튀는 스타일). 같은 인물·같은 포즈를 유지할 필요 없다.
- **배경은 에피소드 주제 장소로 통일** (하객룩이면 결혼식장 로비).
- 그리드에서 통일감이 나도록 공통 조건을 모든 프롬프트에 넣는다: `Full body, centered, vertical 4:5, fashion magazine style.`
- 인물은 성인으로 명시한다 (`in her mid-20s`).
- "섹시하게"를 직접 쓰지 말고 **패션 화보 톤**(glamorous, chic, confident 등)으로 쓴다. ChatGPT 거절이 줄고, 유튜브 연령 제한도 피하기 쉽다.

## 생성 방법

- 프롬프트 하나 = 이미지 한 장. 선택지 4개는 **4번 따로** 생성한다.
- 저장 이름: `assets/01.png` ~ `04.png` (선택지 번호 순서)

## 선택지 구성 요령

- 정답이 하나로 갈리지 않게 **서로 다른 이유로 최악**인 선택지를 섞는다 (금기 / 노출 / TPO 무시 / 함정).
- 하나쯤은 "괜찮아 보이는데?" 싶은 함정 선택지를 넣으면 댓글 논쟁이 커진다.
